# 100-days-of-code-C
100 days of code on C

This repository contains 100 folders (day01 to day100) for organizing daily C programming challenges and solutions during the 100 days of code journey.

## Structure
- `day01/` - Day 1 programs
- `day02/` - Day 2 programs
- ...
- `day100/` - Day 100 programs

Each folder is ready to contain C source files, examples, and any related documentation for that specific day.
